# ⑥ 系统自维护（system）

> 分叉定位：触发后我要做的那个动作是「**改我自己**」——记忆、skill、知识库结构。
> 动作修改的是 Agent 自身的配置/知识，而非外部世界。

## 本分叉承载什么
- 六类归类原则、只写向下路由、路由最多两级、拆分判据、删前先搬内容。
- 红线落点索引的维护（新增/删除/迁移红线须同步改主 `MEMORY.md` 第三节）。
- skill 的创建/修改/安全审计流程；知识库 ingest / lint 流程。

## 填写指引
- 把这类场景下你的**自维护纪律、结构约束、审计步骤**写在这里。
- 任何新增/删除/迁移红线，必须同步改 `MEMORY.md` 第三节落点表。
- 若希望强制加载，把它加入 hook 脚本的 `FILES`。
